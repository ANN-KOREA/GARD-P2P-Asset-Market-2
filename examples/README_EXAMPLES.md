# 예제 데이터 안내

프로젝트 원장은 새로 생성합니다. 예제 자체를 실제 거래·검증 증거로 사용하지 마세요.

이전 GARD Fact2Asset v1 자료를 사용하려면 개인 PC에 보관 중인 Owner ZIP의 비공개 JSON을 `product-studio.html`의 **기존 백업/Fact2Asset v1 가져오기** 메뉴에서 선택합니다. 개인정보·영업비밀 원본이 아닌 합성/비민감 데이터로 먼저 시험하세요.

공개 전시장의 `catalog.json`은 기존 저장소 원본을 그대로 사용하므로 이 업데이트 ZIP에는 포함하지 않습니다.
