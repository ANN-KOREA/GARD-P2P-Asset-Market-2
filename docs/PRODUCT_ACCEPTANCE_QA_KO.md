- FAIL 시험은 오류 재현 방법, 발생한 버전, 데이터 종류, 영향 범위를 남긴 후 수정합니다.
- 수정 후 해당 시험만 재검증하고 전체 기능의 회귀시험을 수행합니다.
- 합격 여부는 코드에 쓰인 문구가 아니라 실제 실행 증거로 결정합니다.
