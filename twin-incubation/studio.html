복원은 기존 데이터와 자동 병합되지 않습니다. 반드시 먼저 현재 원장을 백업하고, 선택한 파일의 구조·건수를 확인한 후 교체를 승인하세요.

새 GitHub → Netlify 전시장 운영 순서

  1. ① 위에서 공개 ZIP을 생성하여 압축을 해제합니다.
  2. ② 파일을 직접 검토하고 공개 가능 자산만 있는지 확인합니다.
  3. ③ GitHub에서 새 저장소를 만들고 ZIP 내용의 파일을 저장소 최상위에 업로드합니다.
  4. ④ Netlify → Add new project → Import an existing project → GitHub → 해당 저장소를 선택합니다.
  5. ⑤ Build command는 비우고 Publish directory는 . 을 지정합니다.
  6. ⑥ 별도 브라우저와 휴대전화에서 실제 공개 URL을 시험하고 증거 위치를 기록합니다.
  7. ⑦ 다른 창업자에게 이를 설명하고 독립 실행을 지원했다면 후속 오너 원장에 기록합니다.
